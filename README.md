# 🥤 Fruit-Drink-Landing-Page

Uma página web interativa desenvolvida com HTML, CSS e JavaScript, apresentando diferentes sabores de sucos de frutas.

A página possui um sistema de navegação por setas que permite alternar entre os produtos. Ao clicar nos botões, as imagens, textos e elementos visuais são alterados com pequenas animações e transições.

## ✨ Funcionalidades

- Navegação entre diferentes sabores de suco
- Botões de anterior e próximo
- Alteração dinâmica das imagens
- Alteração dos textos e elementos da página
- Animações e transições utilizando CSS
- Interações utilizando JavaScript
- Interface visual focada na apresentação do produto

## 🛠️ Tecnologias utilizadas

- **HTML5** 
- **CSS3** 
- **JavaScript**

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido como prática de desenvolvimento Front-end, com o objetivo de aprimorar conhecimentos em HTML, CSS e JavaScript.

O foco principal foi criar uma interface de apresentação de produto com elementos interativos e transições visuais.
